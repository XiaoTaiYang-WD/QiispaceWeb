## 1. 产品概述

### 1.1 产品定位

栖愈 QIISPACE 品牌官网是栖愈 SPA 品牌的线上门户，定位为**高端身心疗愈 SPA 品牌展示型官网**。网站承载品牌形象展示、服务项目介绍、品牌理念传递、门店信息查询等核心功能。

### 1.2 产品目标

| 目标 | 描述 | 衡量指标 |
|------|------|----------|
| 品牌认知 | 传递"自然疗愈、身心栖息"的品牌理念 | 页面停留时长、回访率 |
| 服务转化 | 引导用户从了解服务到预约体验 | 门店页跳转率、电话拨打量 |
| 门店引流 | 为全国各门店导流线下客源 | 门店页面 PV |
| 品牌质感 | 通过视觉与动效建立高端品牌感知 | 用户主观反馈 |

### 1.3 产品形态

- **类型**: 单页应用（SPA），Vue 3 + TypeScript + Vite
- **终端**: 桌面端 + 移动端响应式
- **页面数量**: 4 个核心页面（首页 / 服务介绍 / 关于我们 / 门店列表）
- **内容类型**: 品牌展示型（非电商、非内容管理）

### 1.4 品牌核心信息

- **品牌名**: 栖愈 QIISPACE
- **Slogan**: 于城市喧嚣中，寻一处身心栖所
- **理念**: 「栖」是栖息、停留、安放；「愈」是疗愈、修复、重生。以自然之力，愈身心之疲。
- **调性**: 自然、静谧、专业、温暖

## 2. 目标用户

### 2.1 核心用户画像

| 用户类型 | 特征 | 核心需求 | 典型浏览路径 |
|----------|------|----------|-------------|
| **都市白领** | 25-45岁，工作压力大，肩颈/睡眠问题 | 了解能解决自身问题的 SPA 服务 | 首页 → 服务介绍 → 门店 |
| **品牌探索者** | 首次听说栖愈，通过社交媒体或推荐而来 | 了解品牌是否可信、专业 | 首页 → 关于我们 → 服务介绍 |
| **意向消费者** | 已决定尝试 SPA，正在比较品牌和门店 | 快速找最近门店、服务价格 | 首页 → 门店列表 |
| **回头客** | 已有栖愈消费经历 | 查看新服务、新门店 | 服务介绍 / 门店列表 |

### 2.2 用户场景

1. **小张**，30岁产品经理，长期伏案肩颈酸痛。小红书看到栖愈 → 打开官网确认"深层组织按摩"项目 → 找到最近望京店。
2. **Lisa**，28岁，周末想和朋友做 SPA。浏览服务项目 → 被"芳香精油SPA"吸引 → 找到三里屯店。
3. **王女士**，42岁，长期失眠。朋友推荐薰衣草安睡疗程 → 确认品牌专业度（关于我们）→ 致电预约。

### 2.3 用户旅程

```
                    ┌──────────────┐
         外部入口 ──→│   首页 (/)   │←── Logo 点击
                    └──┬───┬───┬──┘
                       │   │   │
          ┌────────────┼───┼───┼────────────┐
          ▼            ▼   │   ▼            ▼
   ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐
   │服务介绍   │  │关于我们   │  │门店列表   │  │外部跳转   │
   │/services │  │/about    │  │/stores   │  │(电话/地图) │
   └──────────┘  └──────────┘  └──────────┘  └──────────┘
```

**核心转化路径**: 首页 Hero → 热门服务预览 → 服务介绍页（筛选/浏览）→ "预约体验" → 门店列表页 → 致电/到店

**快速转化路径**: 首页底部 CTA "查找附近门店" → 门店列表页 → 转化

## 4. 动效与交互设计

### 4.1 动效总览

设计原则：**自然、流畅、克制**，每处动画服务品牌氛围。

| 动效 | 技术 | 应用范围 | 触发 | 关键参数 |
|------|------|----------|------|----------|
| 分裂文字入场 | GSAP + useSplitText | 首页 Hero 标题 | 页面加载 | delay:0.3s, y:60→0, rotateX:-40°→0, back.out(1.4), stagger:0.03s |
| 滚动显现 | IntersectionObserver + CSS | 全局 `.reveal` | 进入视口(0.1) | y:30→0, opacity:0→1, 0.8s cubic-bezier |
| 3D 卡片倾斜 | CSS perspective + mousemove | `.tilt-card` | 鼠标悬停 | perspective:1000px, rotateX/Y:±8°, scale:1.02 |
| 数字计数 | GSAP fromTo + ScrollTrigger | 首页/关于页统计 | 进入视口(85%) | innerText:0→target, 2.5s, power2.out |
| 磁性按钮 | GSAP + mousemove | `.magnetic-btn` | 鼠标悬停 | 偏移 15%, 0.4s; 回弹 elastic.out 0.5s |
| 背景缩放 | GSAP ScrollTrigger + scrub | 首页 Hero 背景 | 页面滚动 | scale:1→1.3, scrub:0.6 |
| 幕帘揭示 | GSAP + clip-path:inset | 首页品牌故事/关于页 | 进入视口(80-82%) | inset:0 100%→0, 1.4s power3.inOut |
| 视差深度 | GSAP ScrollTrigger + y | `.parallax-depth` | 页面滚动 | scrub:1, speed 可配置 |
| Canvas 粒子 | RAF + Canvas 2D | 全局背景 | 持续 | 数量: w*h/30000 |
| 鼠标光晕 | RAF + radial-gradient | 全局 | 鼠标移动 | 500x500px, 缓动:0.04/0.08 |
| 页面过渡 | Vue `<transition>` | 路由切换 | 导航 | mode:out-in, 入场 0.5s/离场 0.3s |

### 4.2 性能策略

| 策略 | 说明 |
|------|------|
| passive 监听 | 滚动和鼠标移动使用 `{ passive: true }` |
| RAF 动画 | 粒子和光晕使用 `requestAnimationFrame`，卸载时 cancel |
| 单次播放 | ScrollTrigger `toggleActions: 'play none none none'` |
| will-change | 关键动画元素使用 `will-change: transform` |
| 懒加载路由 | 所有页面 `() => import(...)` 动态导入 |
| 图片格式 | JPG 背景图 + SVG 噪点内联 data URI |
